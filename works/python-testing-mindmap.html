一、需要掌握的知识点（建议顺序）

  1. Python 工程基础——语法与数据结构、函数与类、异常处理；虚拟环境 venv / poetry、包管理 pip；装饰器与上下文管理器（理解 pytest fixture 的关键）；文件 IO、正则、JSON / YAML。
  2. 测试核心概念——单元 / 集成 / E2E 的边界；测试金字塔；测试替身（stub / mock / fake）与测试隔离；等价类、边界值、场景法等用例设计方法。
  3. pytest 体系——fixtures 夹具、parametrize 参数化、conftest.py 组织、插件机制与断言重写。
  4. 分层测试能力——接口 / API 测试、UI / E2E 测试、性能压测、数据库测试；异步测试 pytest-asyncio；测试数据构造。
  5. 工程化——覆盖率 coverage、报告 Allure、CI 集成（GitHub Actions）、tox / pre-commit。
  6. 趋势认知——AI 辅助测试：自愈定位、用例生成、失败分析。

建议路径：工程基础 → pytest → 接口测试 → UI 测试 → 报告与 CI → 专项能力与 AI 辅助。先把手写脚本跑通，再谈框架与平台化。
